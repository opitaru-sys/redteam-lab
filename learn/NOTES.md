# Notes

## How Omri wants to be taught
- **Retrieval over reading.** He has plenty of material and can already read it. The
  gap is recall under time pressure. Bias every lesson hard toward closed-book
  retrieval practice and away from exposition
- **Short.** One idea per sentence. No em dashes, ever (brand rule). No hype words
- **Lead with the answer**, reasoning after
- **Honest both-sides.** Tell him where he is wrong. If the evidence is weak, say so
- **Proof over adjectives.** A number, a name or a source beats "significant"
- Known failure mode: building instruments instead of doing reps. If a lesson can be
  replaced by an attempt against a live target, replace it

## Diagnosed weak spots (7 Aug 2026, from the first session post-mortem)
- Reads refusal texture instead of reading the target's own stated spec
- Turns a relative statistic into a categorical rule
- Treats an inference as a fact without running the cheap falsifying test
- Cannot yet name the technique families or defense layers without the doc open
