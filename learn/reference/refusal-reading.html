Two overriding rules

Reroll before you rewrite. Half-worked? Vary one cosmetic or numeric parameter first. It acts like a fresh seed and costs no thinking.

Stop rerolling when the class stops moving. Eight tries in the same class is sampling noise. Change family.

Harvest on a hit

Freeze the output verbatim into the log's response field. The bytes, not a paraphrase.

response holds what came back, never what you sent.

Then advance. An unsaved win did not happen, and in a scored arena it is unscorable.
