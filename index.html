Real attacks are a composition, not one card. An objective is what you want. A wrapper is how you frame the ask, and it does the actual work. A modifier stacks on top. An amplifier multiplies attempts. A channel changes where the payload arrives from. Pick one objective, then one wrapper, then stack if it half-works.
